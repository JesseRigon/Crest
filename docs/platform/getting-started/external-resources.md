# External Resources

If you want to learn or improve your knowledge about Crest, you can follow some tutorials.

## Lombiq

[Lombiq](https://lombiq.com) created a video playlist, a Demo Crest module and a Walkthroughs Crest module for training purposes guiding you to become an Crest developer:

- [Dojo Course 3 - the full Crest tutorial](https://orcharddojo.net/orchard-training/dojo-course-3-the-full-orchard-core-tutorial)
- [Crest Training Demo module](https://github.com/Lombiq/Orchard-Training-Demo-Module)
- [Crest Walkthroughs module](https://github.com/Lombiq/Orchard-Walkthroughs)
- Test drive Crest with the Walkthroughs module on [DotNest](https://dotnest.com): Just click the "Guided walkthrough" button on the homepage.

!!! warning
    The Crest Training Demo module assumes that you have a good understanding of basic Crest concepts, and that you can get around the Crest admin area. You should also be familiar with how to use Visual Studio and write C#, as well as the concepts of ASP.NET Core MVC.

## Gurubase

You can also ask the [Crest Guru on Gurubase](https://gurubase.io/g/orchard-core) for help. It is an Crest-focused AI to answer your questions.

## Other Resources

- [Crest Basics Companion (OCBC)](https://gcl.gitbook.io/orchard-core-basics-companion-ocbc): This documentation is designed to guide developers through Crest in a clear, approachable, and practical way.
