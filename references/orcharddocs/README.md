# OrchardCore reference documentation (inherited)

The upstream OrchardCore documentation tree the hard fork carried in, trimmed to the parts
that still describe platform code Crest keeps: the module and core reference pages,
`topics` and the mechanics guides. The rename replaced "OrchardCore" with "Crest" in the
text, so claims about products, packages and history read oddly; treat it as a reference
on how the stock platform behaves, not as Crest's design. Crest's own documentation is
`docs/`. Removed: the MkDocs site plumbing, community, contributing, releases, samples,
getting-started, branding, the sample themes and the upstream-only guides.
